# Corre em Dia

App de bolso para organizar contas de quem trabalha com entregas.

- **Semana**: o que pagar de segunda a domingo, o que ficou para trás e o que dá para adiantar.
- **Contas**: gastos de toda semana, bloco do dia 15 (meta: pagar no dia 1) e bloco do dia 30
  (meta: pagar no dia 15), com valor diferente por mês e lembrete no Google Agenda.
- **Plano**: adiantamento gradual, metas com data, reserva de emergência de 3 meses e backup.

Os dados ficam só no celular de quem usa (localStorage). Nada é enviado para servidor.

## Instalar no Android
Abra o link no Chrome → menu ⋮ → **Instalar app** (ou "Adicionar à tela inicial").

## Tecnologia
HTML, CSS e JavaScript puro, PWA com service worker (funciona sem internet).
